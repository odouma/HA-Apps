# HA-Apps

Een verzameling eigen Home Assistant add-ons.

## Toevoegen aan Home Assistant

1. Ga naar **Instellingen → Add-ons → Add-on store**.
2. Klik rechtsboven op de drie puntjes → **Repositories**.
3. Voeg deze URL toe: `https://github.com/odouma/HA-Apps`
4. De add-ons hieronder verschijnen nu in de store, onder "Local add-ons"
   (of onder de naam van deze repository).

## Add-ons

- **[Solar Reporter](solar_reporter/README.md)** — houdt elektriciteitstarieven
  bij en verstuurt PDF-rapportages over de opbrengst en besparing van je
  zonnepanelen.
